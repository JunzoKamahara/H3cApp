Updates

The main changes in each version. Each line opens that version's release notes and download on GitHub Releases. Versions before v0.5.0 are on GitHub Releases.

  • v0.8.0 (November 10, 2026) Experimental support for HyperFlow H3 Flash (GGUF), which generates in 4, 6 or 8 steps
  • v0.7.11 (November 7, 2026) SeedVR2 video path (enlarging with less flicker); up to 1920×1088 on a 24 GB Mac
  • v0.7.10 (November 6, 2026) New windows open on an untitled project; move videos between projects
  • v0.7.9 (November 6, 2026) Open-H3 enlarges videos made without a project, and ×2-size videos too
  • v0.7.8 (November 5, 2026) Stack several images into one RefMod, RefMods in Custom Clips too
  • v0.7.7 (November 5, 2026) RefMods (saved references): make, use and manage them in Model Manager
  • v0.7.6 (November 4, 2026) Faster generation from reference images, a plan before each generation, clean new windows
  • v0.7.5 (November 2, 2026) SeedVR2 and Open-H3 regeneration for enlarging; choose the method first
  • v0.7.4 (November 1, 2026) Works around a crash at the start of generation on Macs before the M5; SwiftVR weights pinned to the Apache-2.0-declared revision
  • v0.7.3 (October 30, 2026) Fixes v0.7.2 not generating on Macs before the M5
  • v0.7.2 (October 29, 2026) SwiftVR AI video super-resolution (enlarging that draws texture back in, also as restore-at-4x-then-shrink)
  • v0.7.1 (October 28, 2026) General Settings, a choice of saved quality, and an API access token
  • v0.7.0 (October 26, 2026) The grid and blocks in dark areas fixed (videos kept in HEVC)
  • v0.6.9 (October 26, 2026) Continue enlarged videos; a new Video menu
  • v0.6.8 (October 25, 2026) Enlarge finished videos afterwards, AI upscaling included
  • v0.6.7 (October 25, 2026) Fixed: the export options for the AI label and settings couldn't be unchecked
  • v0.6.6 (October 24, 2026) Continue videos made elsewhere; the faint grid in the picture reduced
  • v0.6.5 (October 23, 2026) Moving the prompt panel, and pinching over it, fixed
  • v0.6.4 (October 23, 2026) AI-generated label, and the prompt and settings recorded in the video
  • v0.6.3 (October 23, 2026) Joined generation with each clip's length, images and audio set one by one
  • v0.6.2 (October 21, 2026) Progress previews while generating
  • v0.6.1 (October 20, 2026) Add Ref2VA later to a registered model
  • v0.6.0 (October 19, 2026) Download and import quantized models (GGUF)
  • v0.5.0 (October 16, 2026) Lip sync and joined generation up to 90 seconds

H3cApp by Junzo Kamahara, Faculty of Data Science, Osaka Seikei University

H3cApp is a macOS app based on h3.c by Salvatore Sanfilippo (antirez) (MIT License). Videos are generated with MiniMax H3, a video generation model by MiniMax, which comes under its own license, the MiniMax H3 Community License.
