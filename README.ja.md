# H3cApp

[English](README.md) | [日本語](README.ja.md)

**文章や写真から、音声付きのAI動画をMacだけで作れるアプリです。** [MiniMax H3](https://huggingface.co/MiniMaxAI/MiniMax-H3)を利用し、モデルをダウンロードしたあとはMac上で動画を生成します。クラウドの動画生成サービスやPython、複雑な設定は必要ありません。

**Powered by MiniMax H3** — H3cAppはMiniMaxの公式製品ではなく、独立したアプリです。

![H3cAppの画面](docs/assets/images/app-window.jpg)

## できること

- **文章から動画を生成**：場面を文章で説明するだけで、音声付き動画を作成できます。
- **写真から動画を生成**：最初の画像や最後の画像を指定できます。
- **参照画像・動画・音声を使って生成**：画像・動画・音声を参照にできます（追加のRef2VAモデルが必要）。
- **声や歌に合わせる**：録音した声や音楽に合わせて動画を生成できます。
- **長い動画を作る**：動画の続きを生成し、複数の動画をつなげられます。
- **便利な機能**：生成途中のプレビュー、プロジェクト管理、対応LoRAの利用など。

## 対応するMac

| 項目 | 動作要件 |
|---|---|
| Mac | **Apple Silicon搭載**のMacBook Air、MacBook Pro、Mac mini、iMac、Mac Studio、Mac Pro |
| チップ | Apple Mシリーズ（M1以降）。高速処理には**M5を推奨** |
| メモリ | **24GB以上を推奨** |
| macOS | macOS 15（Sequoia）以降 |
| 追加ソフト | 不要（配布アプリを利用する場合） |

**メモリについて：** M5・24GBのMacで動作確認済みです。**16GBは未テスト**のため動作を保証できません。**16GB未満のMacでの動作も確認できていません**。Intel Macにも対応していません。

M1〜M4のMacでも、常駐かSSDストリーミングの計算方式を利用できますが、生成速度は機種や設定によって異なります。

## モデルと必要なディスク容量

アプリ本体とは別に、動画生成に使うMiniMax H3のモデルをダウンロードします。

| モデル構成 | 必要な保存容量（目安） | 特徴 |
|---|---:|---|
| **GGUF 標準（おすすめ）** | **約45GB** | 画質と容量のバランスがよい構成 |
| GGUF 軽量 | 約35GB | ディスク容量を抑えたい場合 |
| 公式モデル（BF16・FL2VA） | 約145GB | 量子化していない公式モデル |
| 公式モデル（BF16・FL2VA＋Ref2VA） | 約290GB | 参照画像・動画・音声も使える公式モデル |

表の数字は**モデルファイルの保存容量**であり、必要メモリではありません。GGUFの標準・軽量構成では、文章からの動画生成と最初・最後の画像を指定した生成が利用できます。参照画像・動画・音声を使うには、**追加のRef2VAモデル（約11〜21GB）**が必要です。

M5で高速化用のキャッシュを作る場合は、**モデルごとに約19GB**の追加容量が必要です。Ref2VAも使う場合は、Ref2VA用のキャッシュとしてさらに約19GBが必要です。ダウンロード中のファイルや生成動画の保存用にも余裕を確保してください。モデルは外付けSSDにも保存できます。

詳しくは[GGUFモデルの説明](GGUF.ja.md)を参照してください。

## インストールと最初の動画

1. [リリースページ](https://github.com/JunzoKamahara/H3cApp/releases/latest)から最新版の**H3cApp .dmg**をダウンロードします。
2. .dmgを開き、**H3cApp**を**アプリケーション**フォルダにドラッグします。
3. H3cAppを開き、初回起動の案内に従ってモデルを用意します。最初は**GGUF標準構成**がおすすめです。
4. 「夕暮れの海辺。穏やかな波の音と暖かい光」のような文章を入力し、長さと大きさを選んで**生成**します。
5. 完成した動画を確認し、**「動画を書き出す…」**から保存します。

生成には、Macの性能や設定によって数分以上かかる場合があります。配布版の利用にXcodeやコマンド操作は必要ありません。

画面付きの手順は[はじめての使い方](https://junzokamahara.github.io/H3cApp/getting-started.html)をご覧ください。
